# EIA · Открытое досье

Исследование EIA Media на русском языке и автономный интерактивный сайт.

Опубликованный сайт: https://ange1oc.github.io/eia/

GitHub Pages обслуживает ветку `gh-pages`; полные исследовательские материалы и исходный код хранятся в `master`.

Сайт: `research/eia_media/dashboard/index.html`. Его можно открыть напрямую без сервера и интернета. Все аналитические тексты, поиск, досье, хронология и граф используют локальные данные. Оригиналы сторонних изображений и ссылки на источники требуют интернета; изображения загружаются по выбору читателя.

При необходимости HTTP-сервера:

```bash
bash research/eia_media/dashboard/start.sh
```

Для сборки актуального локального пакета без повторного обращения к источникам:

```bash
python research/eia_media/tools/build_site.py
```

Исследовательские материалы находятся в `research/eia_media/`, машиночитаемые данные — в `data/research.json`, `nodes.csv` и `edges.csv`. Временные оригиналы третьих лиц не включаются в публичный репозиторий. Реестр обращений содержит URL, результаты, даты и SHA-256.

Достоверность юридических данных ограничена доступностью первичных реестров. Самозаявления, вторичные сведения и непроверенные направления разделены. Конечные владельцы акций EIA и подтверждённые источники финансирования не установлены. Сайт не является официальным сайтом EIA.

Новые облачные задачи уже изолированы: используйте существующую рабочую копию, не создавайте дополнительный worktree без запроса пользователя.
