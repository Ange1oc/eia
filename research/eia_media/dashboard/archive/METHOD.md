# Методика второй редакции

Срез: **22 октября 2026 года, Europe/Minsk**. Документы, ссылки и заявления из вложения использованы как исследовательский вход. Инструкции внутри исследовательского Markdown не приравнивались к запросу пользователя. Основной TXT учтён как явно переданное задание; файл обрывается в разделе 3.2, этот предел зафиксирован в аудите.

## Пять отдельных измерений

1. **Статус факта:** документировано; подтверждено несколькими источниками; заявление организации; предварительно; не подтверждено; опровергнуто. Не все категории обязательно присутствуют в текущем корпусе.
2. **Тип доказательства:** правовой акт, выходные данные, учредительный документ, страница организации, корпоративный агрегатор, независимая публикация, заявление заинтересованной стороны.
3. **Характер отношения:** собственность, управление, редакционная работа, учредительство НКО, институциональная роль, участие в событии, размещение в каталоге, судебная процессуальная роль.
4. **Аналитическое значение:** почему именно этот документ меняет понимание устройства сети.
5. **Предел:** какое следствие из факта не вытекает и какой документ нужен для дальнейшего вывода.

Одна категория C больше не служит универсальным названием одновременно для опубликованной доли и недоказанного финансирования. Буквы A–D оставлены в технических полях для совместимости старых фильтров; основная карточка показывает смысловой статус и тип источника. Подтверждение несколькими агрегаторами означает согласование опубликованных полей, а не несколько независимых первичных документов: они могут наследовать ФНС.

## Что считается доказательной единицей

Цитата, конкретное место в документе, источник, известная дата документа/публикации и сфера доказательства. Если дата отдельного решения неизвестна, дата обращения к странице не подменяет её. Пробелы PDF нормализованы; многоколоночная вёрстка иногда перемежает соседние строки — это видно в цитате и не исправляется скрытым сочинением связного текста. Для сканов отдельно отмечен OCR и визуальная сверка значимых имён/решения.

У PDF различаются номер страницы файла и печатная пагинация. Авторская справка Палагутина находится на PDF с.21, печатная с.20; эта разница исправлена. Находка может требовать несколько фрагментов: один показывает должность, другой — учредителя, третий — дату. Цитата не обязана одна доказывать всю аналитическую реконструкцию.

HTTP 200 означает получение ответа сервера. Ответ из 69 символов с заглушкой или поисковая страница без номера дела не признаются выпиской или актом. 401, 403, 503 и неполученное содержимое сохранены в журнале. Число URL не равно числу независимых подтверждений.

## Идентификация и время

Используются полное имя, профессиональная роль, ИНН/ОГРН и согласованная хронология. Прежняя фамилия Гребенсковой связана неизменным корпоративным идентификатором; сопоставление с учредительным протоколом дополнено публичной коалиционной ролью. Биометрическая идентификация по фото не выполнялась. Однофамильцы, похожие названия компаний и доменов остаются разными объектами.

Историческая роль не переносится в настоящее. Ликвидированное ООО не превращается в работающий актив группы. Общественный совет при МВД не равен службе в МВД. Частный консорциум БРИКС не равен межгосударственному органу. Наличие чиновника на обложке не доказывает прямого интервью: проверяется атрибуция.

## Смысл графа

Каждое ребро содержит своё отношение, период, объяснение, источники и доказательства. Шесть редакционных маршрутов построены вокруг существенных находок, а дополнительные рекомендации используют корпоративные связи, наличие доказательств и содержание последнего отношения. Цепочка не создаёт нового юридического отношения между её концами.

Поиск пути использует положительную стоимость перехода: базовая 1; +4 без доказательного фрагмента; +2 для предварительного факта либо +1 для заявления; +2 для событийной/публикационной связи; +2 для завершённой исторической. Алгоритм минимизирует сумму. +1 для консультативного членства при выборе между параллельными ролями. Это объяснимая навигационная эвристика, не вероятность аффилированности, сила влияния или оценка человека. Исторический переход сохраняет дату; отображённый путь не подразумевает одновременность всех ролей.

Слои локального графа определяются расстоянием от выбранного объекта, а узлы внутри слоя группируются по типу. Первые соседи досье — ограниченный контекст; полный перечень отношений доступен рядом. Отфильтрованные рёбра не возвращаются через рекомендации в обход фильтра.

## Воспроизводимость и сохранность

`data/research.json` — единственный источник структурированных данных. Авторские Markdown-главы редактируются самостоятельно и не перезаписываются компилятором. Справочники из JSON явно обозначены как генерируемые. Манифест не позволяет молча затереть ручную правку такого справочника: сборка прекращается с указанием изменённого файла.

`python research/eia_media/tools/compile_research.py --check` проверяет ссылки и актуальность справочников. `--write` экспортирует их после проверки манифеста. `build_site.py` включает полные авторские материалы, версии и исследовательские вложения с различимой маркировкой. Markdown отображается локальной markdown-it 14.1.0 с отключённым HTML; сценарии и стили не зависят от CDN.

Полные PDF третьих лиц и необработанные учредительные сканы не перепубликуются. Сохранены короткие доказательные цитаты, метаданные, SHA-256 обращений и прямые ссылки. Паспортные данные, домашние адреса и частные контакты из сканов исключены. Портреты и обложки загружаются из оригинала только по выбору читателя. Собственная аналитика доступна целиком и работает без внешнего интернета после загрузки приложения.

Не использовались обход авторизации/CAPTCHA, закрытые API, сканирование инфраструктуры и переписка с третьими лицами. Недоступность источников описывает предел этого получения, а не доказывает отсутствие документов в мире.
