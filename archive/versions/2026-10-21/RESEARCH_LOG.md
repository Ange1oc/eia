# Журнал исследования

## 21 октября 2026, начало работы (Europe/Minsk)

- Полностью прочитано исходное задание (BRIEF.txt). Рабочая копия Ange1oc/eia не содержит коммитов и исходного приложения. Создание исследовательских материалов и последующая публикация сайта разрешены пользователем.
- Первоначальные запросы EIA, Google, ФНС, Checko и GitHub API отклонялись прокси CONNECT 403. Сохранён черновик доменов. Пользователь включил режим «Все (без ограничений)»; повторное чтение конфигурации подтвердило unrestricted, а повторные запросы EIA и GitHub API — HTTP 200.
- На просьбу пользователя отдельно проверены example.com, Wikipedia, Python.org, BBC и Mozilla: HTTP 200. Reuters вернул HTTP 401. Это не доказательство доступности всех ресурсов, но подтверждение работы общего доступа вне списка исследовательских доменов.
- GitHub API подтвердил публичность Ange1oc/eia и имеющиеся права admin/push; Pages ещё не включён. Значения учётных данных не сохранялись.
- Получены страницы EIA: главная, руководство, контакты, о нас, реклама, бизнес-портал, журналы, международные новости, сообщения о партнёрствах. URL /ru/editorial-board возвращает 404; это недоступность указанной страницы, а не доказательство отсутствия редакционного совета.
- Поиск Google через обычный HTTP возвращает оболочку с требованием JavaScript, Bing — нерелевантные результаты. DuckDuckGo сначала вернул полезные результаты, затем CAPTCHA; её обход не предпринимался. Brave вернул несколько результатов, затем 429; массовый поиск остановлен.
- Найдены карточки АО ЕИА ГМГ, АНО МКЦ Алекс, ООО Евразийский Рейтинг, компании Екатерины Гребенсковой и ООО Мясной Клуб. Коммерческие карточки рассматриваются как вторичные источники; их автоматические резюме и риск-оценки не принимаются за независимые доказательства.
- Установлена перспективная историческая фамилия Екатерины Гребенсковой: Скареднова, согласно истории карточки юрлица. Это основание проверять старые документы, а не вывод о личных обстоятельствах.
- Получены и извлечены тексты шести полных PDF EIA: Federation №8, Народная дипломатия №3 и №4, Первый №1, MIC 39(1), Геоинформационное моделирование 4(4). Ещё два PDF оказались неполными и не извлеклись; их содержание не реконструируется.
- В выходных данных Federation, Народной дипломатии и MIC обнаружены регистрационные сведения, расходящиеся с карточками на странице контактов. Это документируемое расхождение внутри публичного корпуса. Утверждение о подложности свидетельств не делается; официальный реестр РКН пока недоступен (503).
- RDAP даёт дату текущей регистрации eia.media 29.05.2025. CDX содержит более ранние захваты домена 2018–2019; сами эти записи не доказывают преемственность нынешнего проекта. Ранняя сохранённая HTML-страница оказалась почти без содержательного текста.
- Старый домен Ассамблеи перенаправляет внутренние ссылки на главную нового сайта. Руководство найдено по прямому адресу world-assembly.org/about/leadership. Рабинович указан там как член Высшего консультативного совета и руководитель SHA International ratings center. Это отличается от роли заместителя генсекретаря, заявленной EIA; актуальные полномочия требуют проверки приказом/протоколом.
- Прямой сайт СПбГУ подтверждает профессиональную биографию Дмитрия Гавры. Академические и общественные роли не приравниваются к государственному контролю EIA.

Тексты исходных веб-страниц и PDF хранятся во временном рабочем кеше /workspace/eia-evidence. Они служат проверке; их полная перепубликация без установленных прав не планируется. В публикуемый корпус входят собственная аналитика, короткие доказательные цитаты, точные URL, даты и контрольные суммы полученных документов.

## Систематизация доступного корпуса завершена

- Подготовлены FULL_REPORT, PEOPLE, COMPANIES, CONNECTIONS, TIMELINE, SOURCES, LEADS, FINDINGS, FINANCES, LEGAL, MEDIA и METHOD. Сохранены 48 объектов, 61 атрибутированное отношение и 32 существенных утверждения. Журнал обращений содержит 139 запросов, включая неуспешные и поисковые; это не 139 независимых доказательств.
- Из публично передаваемых данных страницы журналов извлечены все 40 карточек, в том числе семь ранних выпусков, скрытых начальной компоновкой. Каталог не доказывает владение каждым изданием; правовой статус раскрывается отдельно.
- Найдены дополнительные исторические соучредители Гребенсковой/Скаредновой и повторение партнёрства в двух обществах. Проверены отдельные карточки всех трёх компаний: ликвидированы в 2019 году. Автоматический перечень связей не использован как доказательство текущей активности.
- Отдельно найдено ООО «Шёлковый путь» Пешева; одноимённая радиопрограмма не объединена с компанией. Владивостокское ООО с названием «Евразийское информационное агентство» вынесено в исключённые совпадения.
- Разделы поддержки различают возвратное финансирование с параметром 7% и консультацию 0,15 часа. Не установлен перевод денег из этих программ в EIA.

- Существенные ограничения и оставшиеся проверки перечислены в LEADS. Расследование не объявляется установлением конечных владельцев; основной доступный этап завершён с документированными пробелами. Далее выполняется заключительный этап задания: сайт, проверка полноты, браузерные проверки и публикация.
